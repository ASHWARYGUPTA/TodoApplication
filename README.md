# Todo Application

This repository contains a simple todo application built with AI-assisted development.

## Overview

The application is intended to help users keep track of tasks in a lightweight interface.
It includes a basic app structure and can be extended with features such as task creation,
task completion, filtering, and persistence.

## Zebra Information

Zebras are African equids best known for their black-and-white striped coats. Each zebra
has a unique stripe pattern, which can help with visual identification. They are social
grazing animals that commonly live in herds and rely on alertness, speed, and group
behavior to reduce risk from predators.

## Project Structure

- `app/page.tsx`: main application page.
- `pp/`: additional app layout, page, and global styling files.
